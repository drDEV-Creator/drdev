Developed custom for a private retail shop owner.

Familiar Spreadsheet Layouts, Automated Backend

Retain the ledger patterns your cashiers already know, while eliminating calculation mistakes and manual data entry logs.

The Business Requirement

For years, the client maintained their daily sales accounts, bank balances, credits, and payroll splits in Excel sheets. However, editing complex columns on mobile screens led to formula overrides, broken cells, and slow cash closure reports at the end of each shift.

We engineered a customized bookkeeping portal matching Excel's interface row-for-row, so the cashiers required zero training. The database layer automatically aggregates totals, structures Assets and Liabilities, and syncs payroll records to a secure mobile app for the owner.

Core Solution Advantages

  • Familiar tabular columns: zero cashier training required
  • Automated day summary: instant cash/bank balance metrics
  • Sync daemon: automatic web-to-Android data sync
  • Offline availability: caches logs during network interruptions

Key System Interfaces

Designed to facilitate high-speed ledger logs and give remote visibility to the shop owner.

Daily Bookkeeping

Spreadsheet Journal

The entries view mirrors the classic accounting book columns. Cashiers log particulars like cash sale, bank sale, credit sale, returns, and cash withdrawals. Bottom cards auto-summarize Cash Balances, Bank Balances, Total Credits, and Net Profit.

  • Automated running summaries calculating income vs expense splits
  • Keyboard navigation triggers matching traditional excel behavior
  • Input validation to block illegal credit entries and text types
Financial Structure

Accounts Directory

Instead of manually linking sheet tabs, accounts (Cash, Payroll, Bank, Credit Sale, Salary) are organized in a centralized directory. The database aggregates opening and closing assets, expenses, and liabilities automatically on each entry commit.

  • Fuzzy search filter for accounts and ledger items
  • Automated type tagging (Asset, Liability, Expense)
  • Real-time net worth and debt summaries

Shop Payroll Suite

Integrated ledger module engineered to calculate monthly wage logs and track pending payouts.

Payroll Log Management

Tracks employee lists, log dates, payment methods, total payable amounts, paid splits, and pending balances automatically. Handovers are updated immediately.

Technical Infrastructure

Designed for local speed, auto-caching offline databases, and cross-platform synchronization.

Front-End UI

React Tabular Core

Written in React to build a responsive, grid-like bookkeeping interface. Optimized input elements support quick hotkeys and autocomplete entries.

Mobile Client

Flutter Android App

A Flutter-based dashboard compiled for the shop owner's phone. Provides remote, real-time access to daily cashier logs and payroll pending items.

Database Sync

Firebase & Hive Cache

Syncs web records to the mobile client in real time. Local Hive databases cache data offline to ensure continuous shop registry during ISP drops.
