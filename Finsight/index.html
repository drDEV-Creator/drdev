Developed custom for Finite Tax & Global Corp.

Bridging Offline Accounting & Mobile Executives

Tally ERP is the industry standard for financial bookkeeping, but its data remains locked on local desktop office machines. Finsight bridges this gap securely.

The Business Requirement

Finite Global required a secure, background automation bridge that could extract accounting ledgers, invoices, vouchers, and receivables directly from local desktop computers running Tally ERP, transmit them securely to a cloud datastore, and display beautiful financial insights on the client's mobile devices.

The system is split into two primary components: the **Tally Connector Desktop Utility** and the **Finsight Mobile Dashboard App**.

Core Architecture Attributes

  • ODBC data fetching query cycles running locally
  • Automated, secure cloud payloads using REST API hooks
  • Multi-tenant cloud structure partitioned by credentials
  • Flutter mobile dashboard compiling real-time Tally states

Architectural Components

How data travels from local office PCs to secure mobile devices.

Desktop Daemon

Tally Desktop Connector

The desktop application is installed locally on the accountant's PC where Tally runs. It operates quietly in the background, communicating with Tally via local ports to fetch active company books. Once fetched, it structuralizes company ledgers and compiles upload payloads to push to the cloud.

  • Automatic local port verification and connection diagnostics
  • Active company list loading with individual fetch controls
  • Encrypted cloud sync status logs showing precise upload histories
Flutter Mobile App

Executive Mobile Dashboard

The client-side mobile app acts as the front-end dashboard for business owners. After passing credential validation, executives view outstanding receivables and payables, check live bank ledger balances, and drill down into orders and deliveries instantly.

  • Secure user profiles matched with cloud-synced databases
  • Outstanding receivables/payables tiles updated in real time
  • Clean UI displaying order statuses and delivery summaries

Technical Infrastructure

A secure, low-overhead sync pipeline connecting local bookkeeping systems to mobile devices.

ODBC Query Engine

Local Tally API Bridge

Binds locally to Tally's local server port (typically 9000), using XML payload fetches to retrieve ledger accounts, daybooks, and outstanding balance sheets without affecting database runtime performance.

Cloud Daemon

Sync Service Gateway

Encrypts Tally data packets using AES-256 standard protocols before transmitting them over secure HTTP interfaces. Upload logs show successful sync records.

Mobile Framework

Flutter Client Dashboard

A unified Android & iOS dashboard compiled in Flutter, ensuring smooth rendering speeds, visual chart updates, and secure auth verification routines.
